# RideShare — Java 5 · Hyrja dhe lejet



## Çfarë ndërtova
 Shpjego dallimin mes identitetit, rolit dhe pronësisë në aplikacionin tënd.
 Implementova hyrjen dhe daljen me GitHub. Identiteti tregon kush është përdoruesi, roli përcakton çfarë lejohet të bëjë, ndërsa pronësia përcakton cilin udhëtim mund ta ndryshojë shoferi.



## Provat që bëra
### Prova 1: Hyrja, rifreskimi dhe dalja
 Hapa /panel pa hyrë, hyra me GitHub, rifreskova, pastaj dola.
Shkruaj çfarë shfaqej para hyrjes, pas rifreskimit dhe pas daljes.
Para hyrjes, paneli kërkoi kyçjen me GitHub. Pas hyrjes dhe rifreskimit, profili dhe roli shfaqeshin. Pas daljes, përdoruesi nuk ishte më i kyçur.

### Prova 2: Shoferi ndryshon udhëtimin e vet
 Si shofer i ID 2 e ndryshova orën në 08:25.
Shkruaj çfarë u shfaq në panel, listë, detaje dhe SQL Editor. Rikthe 08:15.
Si shofer i ID 2, ndryshova orën në 08:25. Kontrollova panelin, listën, detajet dhe databazën në Neon. Pastaj e riktheva orën në 08:15.



### Prova 3: Veprimi pa leje refuzohet
 Nga formulari i hapur ndryshova ID në 1 dhe provova Ruaj.
Shkruaj mesazhin e refuzimit dhe si verifikove në Neon që ID 1 mbeti 08:00.
Provat shtesë me heqjen e rolit dhe formularin e vjetër janë opsionale pas dorëzimit.
Ndryshova ID-në në 1 dhe provova ruajtjen. Sistemi e refuzoi ndryshimin, sepse udhëtimi nuk ishte në pronësi të shoferit. Në Neon kontrollova që ora e ID 1 mbeti 08:00.
